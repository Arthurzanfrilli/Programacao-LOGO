## Sobre o projeto

Esta ferramenta foi criada para apoiar o entendimento e a performance dos alunos em aula, 
oferecendo uma forma visual e interativa de explorar conceitos fundamentais de programação, como:

- Comandos básicos
- Construção de algoritmos
- Estruturas de repetição (loops)

## Como usar

Basta acessar o link acima em qualquer navegador — não é necessário instalar nada.
O site é dividido em algumas partes principais:

## Área de desenho: 
No lado direito, fica o "tabuleiro" onde a tartaruga se move e desenha o caminho percorrido, seguindo os comandos escritos.
## Meu código: 
No lado esquerdo, é onde os comandos são digitados (ou inseridos pelos botões de atalho, como ANDAR [n] e VIRAR DIREITA). Depois de escrever, clique em ▶ Executar para ver a tartaruga desenhar em tempo real.
## Nossos comandos: 
Uma referência rápida com todos os comandos disponíveis (ANDAR, MOVER, VIRAR DIREITA/ESQUERDA, REPETIR ... vezes [ ... ]) e o que cada um faz — útil para consultar durante o exercício.
Exemplos prontos: 
Botões com desenhos já programados (quadrado, fileira de quadrados, escada, moinho), que carregam o código correspondente para o aluno estudar, executar e modificar.
## Controles auxiliares: 
Ajuste de velocidade da execução, cor do traço, e opções para limpar o desenho, limpar o código ou reiniciar tudo do zero.
